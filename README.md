# Smokertelegram

Многопользовательский сетевой чат на Java: сервер на сокетах и клиент с GUI на JavaFX.
Пользователи хранятся в SQLite, история переписки — локально у клиента.

## Возможности

- Авторизация по логину и паролю (таблица `auth` в SQLite)
- Общий чат и личные сообщения: получатель выбирается в выпадающем списке или кликом по участнику
- Список пользователей онлайн, обновляется при входе и выходе
- Смена ника с сохранением в базе (`/changeUsername`)
- История переписки в файле на каждого пользователя; при входе показываются последние 100 строк
- Закрытие клиента, если вход не выполнен в течение 120 секунд
- Логирование сервера и клиента через Log4j 2 (консоль + файл)

Тестовые пользователи в `mainDB.db`: `user1 / 1111`, `user2 / 2222`, `user3 / 3333`.

## Стек

| Область | Технологии |
|---------|------------|
| Язык | Java 11+ |
| Сборка | Maven (многомодульный проект) |
| UI | JavaFX 15 (FXML) |
| Сеть | `java.net.Socket`, `DataInputStream` / `DataOutputStream` |
| Хранение | SQLite (sqlite-jdbc) |
| Логирование | Log4j 2 |

## Структура

```
ChatServer/   # сервер: MyServer, ClientHandler, авторизация через SQLite
ChatClient/   # JavaFX-клиент: окно входа, окно чата, сетевой слой
```

## Сборка и запуск

```bash
mvn package
```

Пути к базе, логам и истории переписки заданы относительно корня репозитория,
поэтому сервер (`ServerApp`, порт по умолчанию 8189) и клиент
(`com.tlenparty.chat.NetworkClient`) нужно запускать с рабочей директорией в корне —
например, из IntelliJ IDEA.
